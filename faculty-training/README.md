# LeSuccess Faculty Training (Full Day)
## Teaching in the Age of AI: Preparing for the Agentic Future

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitHub](https://img.shields.io/badge/GitHub-Education-blue.svg)](https://education.github.com/)

> **Audience**: College/University teaching faculty  
> **Duration**: 9:00 AM – 5:00 PM (Full Day)  
> **Format**: Talks + Live Demos + Hands-On Labs + Design Sprints  
> **Cost**: 100% Free (using GitHub Education and Student Developer Pack)

## 🎯 Overview

This full-day faculty training program prepares educators to integrate AI and collaborative development practices into their teaching. Faculty will leave with practical, ready-to-use materials including an AI-integrated assignment, a classroom policy, and a redesigned course module for open-source, contribution-based learning.

### What You'll Take Home

✅ **AI Use & Disclosure Policy** – Student-friendly template for your course  
✅ **GitHub Classroom Assignment** – Ready-to-run lab with starter code and autograding  
✅ **Copilot-Aware Assignment Brief** – With prompts and justification fields  
✅ **Contribution-Based Rubric** – Values issues, PRs, docs, and collaboration  
✅ **Agentic Workflow Storyboard** – Template for multi-agent project design  
✅ **Faculty Community Access** – GitHub Discussions for ongoing support

### 🎤 Opening Keynote (9:00–9:30)

**Live Demo Tools** (Free):
- GitHub contribution graphs → global collaboration visualization

### 📖 Session 1 (9:30–10:30) — AI Literacy for Educators
**Focus**: Understanding AI capabilities, limitations, and "agentic" classroom implications

**Activities & Tools** (All Free):
- **Microsoft Copilot (web)**: Idea expansion + prompt comparison exercises
- **Hugging Face Spaces**: Explore open models and agent demos
- **Notion (Student Pack)** or **Google Docs**: Collaborative policy drafting

**Hands-On Exercise**: Draft a 1-page AI Use & Disclosure Policy for your course

**Deliverable**: ✅ AI Use & Disclosure Policy template

[📁 View Session Materials](./session-1-ai-literacy/)

---

### ⚙️ Session 2 (10:45–12:00) — Hands-On: GitHub in Teaching
**Focus**: Make your classroom "open" with real development workflows

**Live Demos & Labs** (All Free):
- **GitHub Classroom**: Create an assignment, add starter code, configure autograding
- **GitHub Codespaces**: Launch a cloud development environment in one click
- **GitHub Actions**: Automate testing and CI for student submissions
- **VS Code/vscode.dev**: In-browser code editing

**Hands-On Exercise**: Build your first GitHub Classroom assignment with starter code

**Deliverable**: ✅ GitHub Classroom assignment + starter repository with README and rubrics

[📁 View Session Materials](./session-2-github-teaching/)

---

### 🤖 Session 3 (12:00–1:00) — Copilot for Learning (Edu)
**Focus**: Use AI responsibly to accelerate understanding, not shortcut learning

**Tools** (Free for verified educators via GitHub Education):
- **GitHub Copilot & Copilot Chat**: Code explanation, test generation, documentation
- **Prompt Engineering**: Teach students to ask better questions
- **Critical Thinking**: Compare AI explanations for deeper understanding

**Hands-On Exercise**: Design a Copilot-friendly assignment requiring students to:
- Paste Copilot chat transcripts
- Justify their AI-assisted choices
- Write tests that Copilot helps generate

**Deliverables**: 
- ✅ Copilot-friendly assignment brief
- ✅ Test-driven development template

[📁 View Session Materials](./session-3-copilot-learning/)

---

### 🔮 Session 4 (2:00–3:15) — Agentic Futures: Multi-Agent Patterns
**Focus**: Understanding "agents" (planners, executors, critics) in educational contexts

**Show & Tell** (Free):
- **Hugging Face Spaces**: Explore simple agent demos (planning → tool use → critique)
- **GitHub Projects**: Model "agent roles" with issues and Kanban boards
- **Team Workflows**: Simulate human/agent task handoffs

**Workshop Exercise**: Map one course project to an agentic workflow:
1. **Planner**: Define requirements and tasks
2. **Coder**: Implement solutions
3. **Tester**: Validate functionality
4. **Documenter**: Explain and justify
5. **Identify**: What remains human-only (ethics, evaluation, narrative)

**Deliverable**: ✅ Project storyboard blending students + AI/agents with checkpoints

[📁 View Session Materials](./session-4-agentic-futures/)

---

### 🏗️ Session 5 (3:30–4:30) — Build the AI-Powered Classroom
**Focus**: Concrete implementation using zero-cost tools stack

**Free Tools Stack**:
- **GitHub Classroom**: Assignment distribution and autograding
- **GitHub Codespaces**: Zero local setup (mind free quotas)
- **GitHub Copilot (Edu)**: Scaffolding with disclosure requirements
- **GitHub Actions**: Automated testing on public repos
- **VS Code/vscode.dev**: Development environment
- **Canva (Student Pack)**: Poster/report templates
- **MongoDB Atlas (Student Pack)**: Database labs
- **Notion (Student Pack)** / **Google Docs**: Lab journals
- **Kaggle/Colab**: Data science notebooks

**Quick Build Options** (choose one or more):
1. Turn an existing lab into a Classroom + Codespaces assignment
2. Add GitHub Actions to run tests automatically on pull requests
3. Create a comprehensive rubric: correctness, docs, reproducibility, collaboration, AI disclosure

**Deliverable**: ✅ Ready-to-run AI-integrated lab (repository + Classroom link + rubric)

[📁 View Session Materials](./session-5-ai-classroom/)

---

**Final Deliverable**: ✅ Personal commitment plan + community membership

## 🚀 Getting Started

### For Faculty Attending Training

1. **Complete Prerequisites**
   ```bash
   # Verify accounts are created:
   - GitHub account ✓
   - GitHub Education verification submitted ✓
   - VS Code installed or vscode.dev accessible ✓
   ```

2. **Review Pre-Reading Materials**
   - Navigate to `session-0-setup/pre-reading.md`
   - Familiarize yourself with GitHub basics
   - Understand AI in education context

3. **Prepare Questions**
   - What challenges do you face in your teaching?
   - What would you like to automate or improve?
   - What concerns do you have about AI in education?

### For Faculty Post-Training

1. **Access Your Deliverables**
   ```bash
   # Clone this repository
   git clone https://github.com/karthik-rameshkumar/GitHub-for-Indian-Financial-Institutions.git
   cd GitHub-for-Indian-Financial-Institutions/faculty-training
   ```

2. **Implement First Assignment**
   - Use templates from `templates/assignments/`
   - Customize for your course context
   - Test with a small group of students

3. **Join Faculty Community**
   - Access GitHub Discussions
   - Share your experiences
   - Ask questions and get support

4. **Iterate and Improve**
   - Collect student feedback
   - Refine policies and rubrics
   - Share improvements with community
