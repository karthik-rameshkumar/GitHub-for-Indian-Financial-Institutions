# AI Use & Disclosure Policy Template

> **Purpose**: Establish clear, student-friendly guidelines for AI tool usage in coursework  
> **Audience**: Students in [Course Name]  
> **Last Updated**: [Date]

## 📋 Overview

This policy outlines how you may use Artificial Intelligence (AI) tools, including GitHub Copilot, Microsoft Copilot, ChatGPT, and similar systems, in this course. Our goal is to help you learn effectively while maintaining academic integrity.

## ✅ Permitted Uses of AI

You **MAY** use AI tools for:

### 1. Learning and Understanding
- ✅ Asking for explanations of concepts, code, or algorithms
- ✅ Requesting different approaches to solve a problem
- ✅ Debugging assistance (understanding error messages)
- ✅ Generating test cases to verify your understanding
- ✅ Learning syntax and best practices

**Example**: "Explain how this sorting algorithm works step by step"

### 2. Brainstorming and Drafting
- ✅ Generating ideas and approaches
- ✅ Creating initial project structure or templates
- ✅ Drafting documentation and comments
- ✅ Exploring design alternatives

**Example**: "What are different ways to structure a web application?"

### 3. Code Review and Improvement
- ✅ Asking for suggestions to improve your own code
- ✅ Checking for potential bugs or edge cases
- ✅ Requesting best practice recommendations
- ✅ Refactoring assistance

**Example**: "How can I make this code more efficient?"

### 4. Documentation and Testing
- ✅ Generating documentation for code you wrote
- ✅ Creating test cases for your implementations
- ✅ Writing comments and README files
- ✅ Explaining your design decisions

**Example**: "Generate unit tests for this function I wrote"

## ❌ Prohibited Uses of AI

You **MAY NOT** use AI tools to:

### 1. Complete Assignments Without Understanding
- ❌ Copy-pasting entire solutions from AI
- ❌ Submitting AI-generated code without modification or understanding
- ❌ Using AI to bypass learning objectives
- ❌ Generating complete assignments end-to-end

### 2. Circumvent Assessment
- ❌ Having AI complete exams or timed assessments
- ❌ Using AI during closed-book tests
- ❌ Submitting AI work as your own without disclosure
- ❌ Avoiding required problem-solving processes

### 3. Violate Collaboration Policies
- ❌ Using AI to complete work meant to be done individually
- ❌ Sharing AI-generated solutions with other students
- ❌ Bypassing pair programming or group work requirements

## 📝 Disclosure Requirements

### For Every Submission, You Must Include:

#### 1. AI Assistance Declaration
Add a section to your submission (README, comments, or separate file):

```markdown
## AI Assistance Declaration

### Tools Used
- [Tool name, e.g., "GitHub Copilot"]
- [Version/date if applicable]

### How AI Helped
[Brief description of what you asked AI to help with]

### What I Learned
[Explanation of what you learned from the AI interaction]

### Changes I Made
[Description of how you modified, validated, or improved AI suggestions]
```

#### 2. Include Conversation Excerpts
For significant AI assistance, include:
- The prompts you gave the AI
- The AI's response
- Your reasoning for accepting/rejecting the suggestion

**Example**:
```
Prompt: "How do I sort a list in Python?"
AI Response: [paste response]
Why I used it: I didn't know the syntax for the sorted() function
What I changed: I modified it to use a custom sorting key
```

#### 3. Code Comments
For AI-generated or AI-assisted code, add comments:

```python
# AI-assisted: Used GitHub Copilot to generate initial structure
# Modified to handle edge case with empty input
def process_data(data):
    if not data:  # Added this check myself
        return []
    # Rest of function...
```

## 🎯 Grading Impact

### Transparent AI Use (Bonus)
Proper disclosure and reflection on AI use will be **positively considered** in your grade:
- +5% for thoughtful AI assistance documentation
- +3% for demonstrating learning from AI interactions

### Disclosure Evaluation Criteria
- **Excellent (5%)**: Detailed prompts, reasoning, modifications, and learning reflections
- **Good (3%)**: Basic disclosure with some explanation
- **Adequate (0%)**: Minimal disclosure, meets requirements
- **Inadequate (-10%)**: Missing or incomplete disclosure
- **Academic Integrity Violation**: See penalties below

### Violations and Penalties
Failing to disclose AI use or prohibited uses will result in:
1. **First offense**: 0 on the assignment + required reflection paper
2. **Second offense**: Failing grade in the course
3. **Serious violations**: Referral to academic integrity committee

## 🤔 When in Doubt, Ask!

### Gray Areas
If you're unsure whether an AI use is appropriate:
1. **Ask before using**: Email instructor or post in discussion forum
2. **Over-disclose**: It's better to disclose more than less
3. **Document everything**: Save your AI conversations

### Questions to Ask Yourself
- "Am I learning from this AI interaction?"
- "Could I explain this code/solution to someone else?"
- "Am I using AI to understand or to avoid understanding?"
- "Would I be comfortable showing this to my instructor?"

## 💡 Best Practices for Learning with AI

### 1. Active Learning Approach
- Start with your own attempt first
- Use AI to check your understanding, not replace it
- Always understand and validate AI suggestions
- Test and modify AI-generated code

### 2. Effective Prompting
- Be specific about what you want to learn
- Ask for explanations, not just solutions
- Request multiple approaches to compare
- Ask "why" to deepen understanding

**Good Prompt**: "Explain the time complexity of bubble sort and why it's O(n²)"  
**Poor Prompt**: "Write code to sort a list"

### 3. Critical Evaluation
- Don't assume AI is always correct
- Test all AI suggestions
- Look for bugs and edge cases
- Compare AI solutions with course materials

### 4. Document Your Learning
- Keep notes on what you learned from AI
- Maintain a log of useful prompts and responses
- Reflect on how AI helped your understanding
- Share insights with classmates (not solutions!)
