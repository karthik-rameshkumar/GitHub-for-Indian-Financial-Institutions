# Session 0: Setup & Pre-Reads

> **When**: Before training day  
> **Duration**: Self-paced (30-60 minutes)  
> **Format**: Self-guided setup and reading

## 🎯 Goals

1. Verify access to all required tools and platforms
2. Complete GitHub Education verification
3. Familiarize yourself with AI in education concepts
4. Ensure everything is free and accessible

## ✅ Setup Checklist

### Required Accounts (All Free)

#### 1. GitHub Account
- [ ] Create account at [github.com/signup](https://github.com/signup)
- [ ] Verify email address
- [ ] Complete profile (add your institution)

#### 2. GitHub Education Verification
- [ ] Visit [education.github.com/benefits](https://education.github.com/benefits)
- [ ] Click "Get benefits for teachers"
- [ ] Upload proof of employment (faculty ID, official email, etc.)
- [ ] Wait for approval (typically 1-3 days)

**Benefits Unlocked**:
- GitHub Copilot for free (education)
- GitHub Codespaces additional quota
- Access to Student Developer Pack offers
- GitHub Classroom unlimited organizations

#### 3. Development Environment
- [ ] **Option A**: Install [VS Code](https://code.visualstudio.com/) (recommended)
- [ ] **Option B**: Verify access to [vscode.dev](https://vscode.dev) (browser-based)

#### 4. Microsoft Copilot
- [ ] Access [copilot.microsoft.com](https://copilot.microsoft.com/)
- [ ] Verify you can generate text responses
- [ ] Test with a simple prompt: "Explain GitHub in education"

### Optional But Recommended

#### 5. GitHub Classroom
- [ ] Visit [classroom.github.com](https://classroom.github.com)
- [ ] Sign in with your GitHub account
- [ ] Explore the interface (no setup needed yet)

#### 6. Additional Tools
- [ ] **Kaggle** account: [kaggle.com/account/login](https://www.kaggle.com/account/login)
- [ ] **Google Colab**: Verify access with your Google account
- [ ] **Hugging Face**: [huggingface.co/join](https://huggingface.co/join)

## 🛠️ Troubleshooting

### GitHub Education Verification Taking Too Long?
- Check your spam folder for verification email
- Ensure you used your official institution email
- Contact [GitHub Education Support](https://support.github.com/contact/education)
- Don't worry - we can work around this during training

### Can't Install VS Code?
- Use [vscode.dev](https://vscode.dev) in your browser
- Or use [github.dev](https://github.dev) directly from any repository
- No installation required!

### Microsoft Copilot Not Working?
- Try a different browser
- Clear cache and cookies
- Use an incognito/private window
- This is optional for most sessions
